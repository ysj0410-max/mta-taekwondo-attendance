🔥 Firebase 실시간 동기화

⚪ 미연결(로컬 모드)
설정을 저장하고 연결하면 실시간 동기화가 시작됩니다.
⚠️ 위 「이 기기 역할」은 안내·연습용입니다 — 실제 권한은 로그인한 계정의 서버 roles/{UID} 문서가 정합니다. 서버 역할이 tablet(또는 미등록)이면 여기서 「관리자 PC」를 골라도 관리자 권한(원생 개인정보·원비·이전)은 생기지 않습니다.
🧹 이 태블릿의 개인정보 비우기역할 확인 전
태블릿에는 이름·부서·수업·띠·상태만 있으면 됩니다. 이 버튼은 전화번호·생년월일·티콘 ID·특이사항·원비·상담·차량·쿠폰·문자 로그를 이 기기에서만 비웁니다. 등록된 관원 얼굴(tdk.faces.v1)과 Firebase 연결 설정은 그대로 남습니다.
출석 태블릿 역할에서만 쓸 수 있습니다 — 서버(Firestore)의 자료는 지우지 않습니다.
마지막 동기화: 아직 없음
🧪 모의 권한 테스트 (가짜 원생 3명)아직 실행 전
실제 Firebase에 연결하기 전에, 가짜 원생 3명(김민준·이서연·박지호)으로 관리자 PC와 출석 태블릿이 보는 정보가 어떻게 다른지 이 화면에서 바로 확인합니다. 가짜 원생은 화면 안에서만 쓰고, 이 기기에 저장된 원생 명단은 건드리지 않습니다.
위 버튼을 누르면 관리자 PC와 태블릿의 차이를 한 줄로 보여 줍니다.
Firestore 경로관리자 PC출석 태블릿
태블릿에 내려가는 것은 kioskStudents(이름·부서·수업·띠·상태)와 출결·출석 화면 설정뿐입니다. 원생 전화번호·생년월일·티콘 ID·특이사항(students), 원비(tuition), 상담(counsel)은 서버 규칙 firestore.rules가 차단합니다. 이 표의 「차단」은 그 규칙의 허용 목록과 같게 계산한 값이고, 실제 차단은 Firebase에 연결한 뒤 서버가 합니다. 두 기기 동기화 자체를 연습하려면 「🧪 모의 모드로 켜기」 후 탭 2개로 열어 보세요(자세한 순서는 SETUP_GUIDE 12장).
🔑 Firebase 로그인 — 역할마다 다른 계정로그인 안 됨
이 기기의 역할은 관리자 PC 입니다 — 아래 관리자 PC 계정으로 로그인하세요.
👨‍💼 관리자 PC 계정원생 전체 정보·원비·상담까지 읽고 쓰기
📱 출석 태블릿 계정이름·띠·출결만 · 개인정보 없음
Firebase 콘솔 → Authentication 에서 만든 계정으로 로그인하세요. 관리자와 태블릿은 서로 다른 계정이어야 합니다.
관리자 PC와 출석 태블릿은 반드시 서로 다른 Firebase 계정을 씁니다. 태블릿 계정은 출석 화면용 최소 정보(이름·부서·수업·띠·상태)와 출결 기록만 읽고, 원생 전화번호·생년월일·티콘 ID·특이사항·원비·상담·설정은 서버 규칙이 전면 차단합니다. 태블릿에서 찍은 출석의 보호자 문자는 켜져 있는 관리자 PC가 대신 발송합니다(태블릿에는 전화번호가 없기 때문).

무료 요금제(Spark) 하루 한도 기준이며, 80%에서 노란 경고, 100%에서는 유료로 자동 전환하지 않고 동기화만 멈추고 기록은 이 기기에 보관됩니다. 합산 값은 참고용이며, 동기화를 멈출지는 이 기기의 추정치와 서버의 한도 초과 응답으로 판단합니다.
📨 전송 대기 · 최근 동기화대기 없음
출결·수정 기록은 먼저 이 기기(tdk.fbOutbox.v1)에 안전하게 쌓이고, Firestore 서버 저장이 확인된 뒤에만 목록에서 지워집니다. 인터넷이 끊겨도 찍은 기록이 사라지지 않고, 연결되면 자동으로 다시 보냅니다.
🗑️ 실패 비우기는 서버 규칙에서 거부되어 영구 실패한 항목만 지웁니다 — 대기 중인 출결은 건드리지 않습니다. (출석 태블릿은 출결만 올릴 수 있으므로, 원생·원비 같은 항목은 처음부터 보내지 않습니다.)

관장님 구글 드라이브 안의 「경희대MTA태권도 백업」 폴더에 관원 명단 · 얼굴 · 출석 이력 · 원비를 mta-taekwondo-backup-latest.json으로 저장하고, 날짜별 사본도 함께 남깁니다. 태블릿을 바꾸거나 브라우저 저장소를 지워도 📥 드라이브에서 불러오기로 그대로 이어 쓸 수 있어요(새 도장폰·PC에서 이어쓰기). 처음 한 번만 📋 Apps Script 코드 보기/복사의 4단계(약 2분)를 따라 웹 앱 주소를 만들면 됩니다. 웹 앱 주소는 관장님 드라이브에만 연결되는 긴 비밀 주소라, 화면을 다른 사람과 공유하거나 주소를 메신저에 그대로 붙여넣지 마세요.
앱 열 때 자동 동기화를 켜 두면 앱을 열 때마다 드라이브 최신 백업과 이 기기를 자동으로 맞춥니다 — 드라이브가 더 최신이면 확인 없이 이 기기에 자동 적용, 이 기기가 더 최신이면 드라이브로 자동 백업합니다. 바꿔 쓴 기기가 비어 있으면 드라이브 백업을 그대로 받아오고, 빈 데이터로 드라이브 백업을 덮어쓰지는 않습니다. 인터넷이 없을 때는 아무것도 바꾸지 않고 다음에 열 때 다시 확인합니다.

ℹ️ 이 프로토타입에 대해

명단·출석 기록·설정은 모두 이 브라우저(localStorage)에 저장됩니다. 얼굴 특징값(128개 숫자)도 이 태블릿에만 저장되고 어디로도 전송되지 않으며, 얼굴 사진 원본은 저장하지 않습니다(작은 썸네일만 선택 저장). 무료문자 자동발송을 켜면 문자 발송에 필요한 이름·번호·문구만 입력한 웹훅 주소(도장폰 MacroDroid)로 전송되고, 그 밖의 데이터는 어디로도 가지 않아요. 태블릿에서 실제로 쓰려면 이 파일을 태블릿에 저장해 열거나, 웹에 올려 홈 화면에 추가하면 됩니다. 실제 운영 시에는 여러 기기 기록 동기화·개인정보 보관을 위해 서버와 DB가 필요합니다. 다만 위의 ☁️ 구글 드라이브 자동 백업을 설정하면, 서버 없이도 관장님 개인 드라이브에 하루 한 번 자동으로 백업하고 다른 기기(태블릿↔도장폰↔PC)에서 되살릴 수 있어요.
